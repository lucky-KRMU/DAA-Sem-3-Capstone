### Project Overview & Requirements

* **Application Goal:** Develop an integrated Python application combining algorithms from previous lab assignments to prioritize parcels, optimize package selection, determine the shortest delivery routes, and compare algorithmic runtime performance.
* **Submission Requirements:** Submit the complete project via file upload or an accessible GitHub repository containing:
* Source code
* Documentation
* Sample datasets
* Screenshots & runtime charts
* Execution steps



---

### Project Phases & Evaluation Rubric

| Phase | Meaningful Title | Task to be Completed | Evidence / Submission | Marks |
| --- | --- | --- | --- | --- |
| **Phase 1** | Courier Problem Design and Planning | Design the courier-planning problem, define parcel attributes, delivery points, graph format, and required algorithms.
